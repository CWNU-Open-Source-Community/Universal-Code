Traverse Board · 针路簿 macOS 本地试用说明
==========================

从下载的产品 ZIP 解压后，直接双击同目录 TraverseBoard.app；无需安装 Go、Node 或 Xcode。
需要 macOS 12（Monterey）或更新版本。
以下命令在解压后的产品目录执行；源码构建后先进入 build/desktop/。

推荐入口
--------
直接打开应用：

    open ./TraverseBoard.app

默认入口启用安全控制面；不启用完全访问、Debug 最大权限、完整
CDP、后台唤醒/定时 Worker 或 Agent 持久终端。历史文件名
Start-Prayu-Operator-Preview.command 只是同一默认入口的兼容快捷方式。显式只读入口为：

    ./TraverseBoard.app/Contents/MacOS/cyberagent-desktop --safe-view

启动器与指南位于 build/desktop/ 目录，仅用于本地产品测试，不是正式发行包。

从源码构建
----------
构建前请把 Node.js 切换到与 CI 一致的 24 基线（例如 nvm use 24），再运行：

    ./scripts/build-desktop-darwin.sh

Node 版本不符时脚本会在前端检查前明确报错；如果 web/dist 已经构建好，
也可以用 -SkipFrontend 跳过前端步骤。构建还需要 Xcode 命令行工具
（codesign）和 Go 1.26.9。

首次接入真实模型
----------------
1. 打开左侧"模型切换"，或进入"设置与账户 > 模型与配置"。
2. 在模型设置中保存 API Key；macOS 构建已接入系统 Keychain，不提供明文回退。
   系统可能要求解锁或授权。拒绝、取消或锁定会显示操作错误；不同 ad-hoc
   构建之间的升级授权体验仍需实际应用验收。
   也可在启动前为 mimo、deepseek 或 anthropic 设置对应环境变量（例如
   DEEPSEEK_API_KEY、DEEPSEEK_BASE_URL、MIMO_API_KEY、MIMO_BASE_URL、
   CYBERAGENT_ANTHROPIC_API_KEY）。环境变量优先于 Keychain，修改后需重启。
   API Key 不写入 SQLite、日志或事件流。

   本地 Ollama 无凭证，只需显式设置 CYBERAGENT_OLLAMA_BASE_URL（仅 loopback
   http，默认 http://127.0.0.1:11434）与 CYBERAGENT_OLLAMA_MODEL；请先自行
   安装 Ollama 并 pull 模型，针路簿不会自动安装或下载。

   使用已配置环境变量的终端启动：

       ./TraverseBoard.app/Contents/MacOS/cyberagent-desktop

3. 依次点击 Provider 的"连接诊断"和"Harness 验证"。Harness 验证会发起最多
   两次真实、受限的模型请求，但不会执行 Shell、文件、浏览器或工具动作。
4. 在"模型路由"中为 code（或所需路由）选择已验证的 Provider/模型并保存。

当前 Standard Code 首次向导要求 Go 证明 Local Sandbox adapter 可用。该 adapter
目前是 Windows-first，在 macOS 上保持不可用；界面不会伪造 readiness 或回退宿主执行。

真实对话
--------
1. 点击"新建任务"，选择工作区并创建 Run。
2. 在底部输入区输入消息并发送。
3. 针路簿会创建或复用该 Run 的 Session，持久化用户消息，执行一个有界
   Supervisor step，并把真实 Provider 回复写回会话。刷新或重启后可继续读取。

打开工作区
----------
"打开工作区"只使用固定 /usr/bin/open 启动已确认的外部应用（Finder、
Terminal、Antigravity、PyCharm、WebStorm、Visual Studio Code），只传递已
登记的目录，不执行任意命令。

语言
----
默认语言为中文。进入"设置与账户 > 个人 > 常规 > 语言"可一键切换中文和
English；选择保存在本机界面存储中。

当前限制
--------
- Keychain 存储已实现；锁定、取消、重启和不同构建升级仍需实际应用验收。
- 可通过"打开工作区"启动独立的 Terminal.app。代码中已有 macOS Bash PTY
  后端，但内嵌 Debug 用户终端仍缺少 macOS 锁屏/休眠边界监控；不要添加
  --enable-user-terminal，它会因监控不可用而启动失败。
- Local Sandbox、受限浏览器与完整 CDP 的 Windows 平台边界在 macOS 上
  仍不可用，不会自动回退到宿主执行。独立 Terminal.app 不代表沙箱能力。
- 本机产物只有 ad-hoc 签名，未公证，release_ready=false；从其他机器拷贝
  打开时可能需要在 Finder 中右键选择"打开"。
- 数据目录：~/.cyberagent-workbench。不要把 API key、cyberagent.db 或凭证
  截图提交到 Issue。若启动失败，请保留本地数据并记录稳定错误代码。

Traverse Board macOS Local Test Guide
============================

After extracting the product ZIP, double-click TraverseBoard.app in that directory.
Requires macOS 12 Monterey or later.
Go, Node and Xcode are only build dependencies. Run the commands below from the
extracted product directory; after building from source, first enter build/desktop/.

Recommended entry point
-----------------------
Open the application directly:

    open ./TraverseBoard.app

The default enables the safe control plane. It does
not enable danger-full-access, maximum Debug, Full CDP, background wake/scheduled
workers, or an Agent-controlled persistent terminal. The historical
Start-Prayu-Operator-Preview.command filename is only a compatibility shortcut.
The explicit read-only entry is:

    ./TraverseBoard.app/Contents/MacOS/cyberagent-desktop --safe-view

The launcher and this guide live under build/desktop/ and exist only for local
product testing; they are not a distribution package.

Building from source
--------------------
Switch Node.js to the CI-pinned 24 baseline first (for example nvm use 24),
then run:

    ./scripts/build-desktop-darwin.sh

A mismatched Node version fails fast before the frontend checks; use
-SkipFrontend when web/dist is already built. Building also requires the
Xcode command line tools (codesign) and Go 1.26.9.

Connect a real model
--------------------
1. Open Model selection, or Settings and account > Models and providers.
2. Save the API key in model settings. macOS builds use the system Keychain
   without a plaintext fallback. macOS may request unlock or access approval;
   denial, cancellation and locking are reported as operation errors. Upgrade
   authorization between different ad-hoc builds still needs application testing.
   Environment variables are also supported: set the matching variable for
   mimo, deepseek, or anthropic before launching (for example DEEPSEEK_API_KEY,
   DEEPSEEK_BASE_URL, MIMO_API_KEY, MIMO_BASE_URL, CYBERAGENT_ANTHROPIC_API_KEY).
   Environment variables take priority over Keychain and require a restart after
   changes. API keys are not written to SQLite, logs, or events.

   Local Ollama is keyless: set CYBERAGENT_OLLAMA_BASE_URL (loopback http
   only, default http://127.0.0.1:11434) and CYBERAGENT_OLLAMA_MODEL
   explicitly. Install Ollama and pull the model yourself first; Traverse Board never
   installs or downloads.

   Start from a terminal with your environment already configured:

       ./TraverseBoard.app/Contents/MacOS/cyberagent-desktop

3. Run Provider diagnostics, then Harness qualification. Qualification
   performs at most two bounded real model calls and executes no shell, file,
   browser, or tool action.
4. Select the qualified Provider/model for the code route (or another required
   route).

The Standard Code first-run wizard requires a Go-proven Local Sandbox adapter.
That adapter is currently Windows-first and remains unavailable on macOS; the UI
does not fabricate readiness or fall back to host execution.

Real chat
---------
1. Choose New task, select a workspace, and create a Run.
2. Send a message from the composer.
3. Traverse Board creates or reuses the Run Session, persists the user message, runs one
   bounded Supervisor step, and stores the real Provider response. Refresh and
   restart recovery use the same durable conversation.

Open Workspace
--------------
Open Workspace launches only operator-confirmed external applications through
the fixed /usr/bin/open (Finder, Terminal, Antigravity, PyCharm, WebStorm,
Visual Studio Code) and passes only the registered directory; it never runs a
command.

Language
--------
Chinese is the default. Use Settings and account > Personal > General >
Language to switch between Chinese and English. The choice is stored locally
for the interface.

Current limits
--------------
- Keychain storage is implemented. Locking, cancellation, restart and upgrades
  between different builds still require application testing.
- Open Workspace can launch the separate Terminal.app. A macOS Bash PTY backend
  exists, but the embedded Debug user terminal still lacks macOS lock/sleep
  boundary monitoring. Do not add --enable-user-terminal: startup fails when
  that monitor is unavailable.
- Local Sandbox, the restricted browser and Full CDP still depend on Windows
  platform boundaries and remain unavailable on macOS, with no automatic host
  execution fallback. The separate Terminal.app is not a sandbox.
- The local artifact is only ad-hoc signed and not notarized;
  release_ready=false. When opened after being copied from another machine,
  you may need to right-click and choose Open in Finder.
- Data directory: ~/.cyberagent-workbench. Never attach API keys,
  cyberagent.db, or credential screenshots to an issue. For startup failures,
  preserve local data and record the stable error code.
