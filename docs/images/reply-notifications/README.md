# 回复提醒页面验证

截图由真实 Chromium 加载生产构建并连接 `cmd/workbenchjourney` 的临时服务后拍摄。
`before.png` 为父提交 `10311148`，`after.png` 为此 PR 的设置页；两张均为 1280 × 1200。
`after-narrow.png` 为 600 × 900 窗口滚动到通知设置后的画面。没有用静态 HTML 代替应用。

已验证：默认关闭、浏览器通知授权、模式选择、测试通知；在纯文本输入中发送测试任务，
真实服务执行文件读取并生成公开回复后，页面调用原生 Notification 构造器生成一次回复通知。
测试时仅用透明 Proxy 记录构造器参数，仍调用浏览器原生实现；没有替换通知返回结果。
首次在富文本编辑器中输入的 harness 标记被 Markdown 转义，临时 Provider 拒绝该测试请求；
改用该 harness 既有纯文本路径后完成。失败回执未触发回复通知。

已检查窄窗口布局。本批未验证原生桌面窗口的操作系统通知弹层；不支持 Notification 的窗口
会禁用该设置并显示原因。系统通知的实际展示也受浏览器权限与系统勿扰模式影响。
