首个正式版本的源码与发布准备。英文称号：**First Voyage**。

## 首版范围

- **连续对话与工作区**：在同一任务中使用草稿、文件和图片附件、计划、工具记录、改动审阅及恢复入口；保留已合并的 CI、PowerShell 5 启动与失败恢复修复。
- **更少审批**：显式选择当前任务的 Full Access 后，普通文件创建、修改、不覆盖目标的移动和派生为创建/修改的回退可自动授权。文件删除仍需确认。宿主命令可联网，并在适用条件下使用系统代理；其他权限档保持各自边界。
- **首次模型接入**：未配置可用模型时先进入接入流程，保存并检查 Provider 后回到原草稿，保留附件与所选模型；不会擅自发送。额度不足与协议不兼容分别提示。
- **搜索与引用**：支持 Responses 原生搜索的 Provider 优先使用托管搜索；不支持时给出明确状态。另有显式普通网页后端，以及 GitHub Issue/PR、Hacker News 和 RSS/Atom 来源读取，复用快照与引用记录。
- **诊断与恢复**：当前任务可显式检查搜索条件；CLI 网页和文件审阅支持批准/拒绝后的前台续跑。CLI 退出后没有后台审批调度器，也不承诺所有宿主命令审批都能自动续跑。
- **设置整理**：普通入口不再展示五类历史任务的全局路由表；Inspector 与 Skill 包卡片补齐留白、说明间距和窄屏排版。

## 兼容与升级

- 数据库迁移至 schema 166，保留既有迁移与操作收据。不支持通过旧版程序直接打开已升级数据库；升级前应保存原数据备份。
- `cyberagent` CLI、Go module、`CYBERAGENT_*` 环境变量、数据目录、凭据标识和安装 identity 保持兼容；发布称号不会改写这些标识。
- 依赖保留主线已合并的 `golang.org/x/image` 与 `js-yaml` 修复。本版本不通过降低校验或跳过测试来改变发布资格。

## 验证边界

本次整合后的本地检查（Windows，Go 1.26.5 / Node 24.14.0）：

- 前端全套 152 个文件、1188 项测试通过（`--maxWorkers=2`）；生产构建与 TypeScript 检查通过。
- Go 全仓编译、受影响包 `go vet`、OpenAPI Go 黄金文件及 TypeScript 生成一致性通过。
- 命令环境/代理合并的定向 race，恢复、schema 163–166、CLI 审批、搜索诊断的定向 race，以及桌面连接器接线检查通过。
- 网页证据、模型适配/资格、文件操作、执行权限与工具网关相关包，以及发布元数据、协议登记和 Surface 门禁检查通过。

首次高并发前端检查有一条 5 秒超时，隔离该文件 8 项通过，随后以两个 worker 完整复验通过；未提高超时或修改断言。首次多包 Go race 中 desktop 包因 Windows 共享测试互斥锁已存在而未开始测试，单独运行桌面接线检查通过。首次失败记录保留，不冒充全量 Go 套件或 Windows 沙箱验收通过。CI 使用的 Go 1.25 环境及远程结果另见 PR。

历史验收只证明当时的具体源码与环境：

- v16 设置排版覆盖两页、四种尺寸/缩放/主题组合，无卡片越界；既有 12 项设置测试、类型检查、前端和 Windows 构建通过。该轮未做原生 Windows DPI 验收。
- 先前真实公开来源验收取得 GitHub、HN 和 Feed 数据，保存快照与引用，并完成无额外网络请求的数据库重开重放。GitHub 当时使用显式进程级直连条件，不能推出所有代理环境均可达。
- 权限、迁移、模型接入与搜索恢复有定向测试及部分 race 证据；这些结果不等于完整真实模型用户链路通过。

以下仍未验收或未通过，发布名称不会改变结论：

1. 最新测试 Provider 的模型调用返回 HTTP 402（余额不足）；尚无首次真实 GUI 回复及连续 Full Access「修改 → 重命名 → 构建 → 联网 → 引用」的通过证据。
2. DeepSeek Responses 不提供本次所需的托管 `web_search`；原生搜索用户链路仍需支持该能力且有可用额度的 Provider。DDG 在部分实测中返回机器人挑战。
3. 同一真实 Run 的超长搜索结果收据化、上下文压缩及精确历史回读尚未贯通实测；规则摘要回退可能遗漏较早纠正，见[公开验收记录](../UX_PUBLIC_REVIEW_STATUS.md)。
4. 本地 v16 前的广泛 Go 检查曾遇到旧迁移夹具与外部 Git 夹具问题。此次整合保留 #200 的对应修复，当前候选以新 CI 结果为准，不能引用 #200 的绿色结果替代。
5. 签名发行、Store 安装及 Windows 10/11 的 DPI/中文输入生命周期矩阵尚未完成；Mac 原生打包复验已通过，但公证与真机用户链路仍未验收。
