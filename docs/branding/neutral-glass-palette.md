## 来源与盘点口径

截图中的紫色来自 `web/src/v2/styles.css` 的 `--v2-accent: #6b55ed`。
这个独立常量绕过了共享主题，83 条 CSS 声明在 17 个文件中引用该 token。
供应商图标槽、审批与恢复卡片、开关、背景和头像还定义了各自的彩色渐变。

盘点覆盖 `web/src` 中全部 24 个 CSS 文件，以及 TS/TSX 中的颜色常量。
CSS 使用 PostCSS 解析声明，记录 hex、rgb、hsl、white、black 的出现次数、
原始写法和规范化 RGBA。包含回退值与历史定义；这些数量表示维护复杂度。
原始品牌图片、用户内容、第三方编辑器和终端输出使用各自的内容语义。

## 材质约定

- 强调操作使用不透明白色填充 `--prayu-primary-bg`，深色文字
  `--prayu-primary-fg`，配合边缘高光、轻阴影和明确边框。hover 使用
  `--prayu-primary-hover`。主按钮、图标槽和选中控件一起核对前景与背景。
- light（浅色）使用白/浅灰面板；dark（深色）接替原 glass 的中性深灰玻璃材质，
  面板填充为 88–96%。glass 展示名称改为「雾透」，恢复 #295 前的灰蓝透色：
  窗口底色 14%、主面板 30%，侧栏保留淡青灰混色。持久化主题值保持不变。
  浅色主按钮在三种主题中保持白底深字。
- 玻璃感来自层次、模糊、细边与反光。雾透保留冷灰材质底色；界面不叠加
  彩色光晕或放大背景饱和度。V2 的强调色和焦点色直接引用共享主题。
- 普通提示、等待、就绪和连接状态使用中性材质，通过文本、图标和状态标记
  传达含义。实际错误与破坏性操作使用共享 danger；代码增删保留 diff 色。
- 终端采用固定中性深色画布、灰白文字和光标，保留六种 ANSI 内容色。
- `prefers-reduced-transparency` 回退到实色并关闭模糊；高对比模式使用明确
  边框；forced colors 跟随系统 Canvas、Button 和 Highlight 颜色。

新增组件复用这些语义 token。组件 CSS 使用 `var()` 关联用途，具体颜色值
集中在共享主题。字体、布局、权限、任务状态和用户输出格式沿用原有行为。

## 阅读与交互补充（2026-10-11）

- 保留 JetBrains Mono 与现有中文后备字体。正文使用 15px、1.7 行高、400
  字重；标题与强调使用 600。代码块使用 13px、1.6 行高，保留原始代码、
  缩进和局部滚动，语言标签与复制操作放在独立栏中。
- 中文字体提供 400、500、600、700 静态字重，因此本轮保留正文 400，避免
  直接将全站改成 430 后产生中英文字重匹配差异。字重可以按真实平台观察
  继续调整；连字与斜线零不作为中文基线修正手段。
- 长文使用段落、列表、标题与表格的层级分隔。表头保留原始大小写；技术 ID
  放入可展开和复制的执行信息区，任务名称与操作入口优先显示。
- 普通面板与浮动面板分别复用共享阴影 token。深色输入面板保留原玻璃的
  高浓度填充、边缘高光和 20px 模糊。雾透输入面板使用 24% 填充、细边与轻阴影，
  移除斜向整面高光和底部重复叠色；浮动表面使用 90% 填充，输入框内的菜单
  延续实色背景以隔开后方内容。
  白色主操作填充和已有错误语义色继续沿用共享主题。
- 动效用于短暂的悬停、焦点和主动展开反馈。执行信息的高度过渡为 180ms，
  使用特性检测；键盘展开与旧浏览器直接展开。会自动展开的活动记录保持即时反馈。
  减少动态模式禁用动画与过渡，原有降低透明度和强制颜色回退继续生效。
- 复制等待使用保留键盘焦点的不可用状态，并阻止重复请求；复制结果可被
  辅助技术读取。失败时引导用户选中完整 ID 手动复制。
